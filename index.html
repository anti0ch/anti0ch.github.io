funes

agent memory · github.com/anti0ch/funes

foodplanner

local-first meal planning · live demo · private repo

a household budgeting and meal-planning app. no cloud, no accounts. the auto-planner solves a real combinatorial problem: picking recipes that share ingredients (so the parsley you buy monday doesn't rot before thursday) is max-coverage, so it runs a seeded greedy pass with swap-based local search, weighted by how fast each ingredient actually spoils. the source is private, since it holds our real grocery data, but the demo runs on read-only sample data if you want to poke around.

  • sqlite
  • local-first
  • max-coverage
